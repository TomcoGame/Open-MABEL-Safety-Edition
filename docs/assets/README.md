Black/charcoal, white and safety yellow are the design palette. The engineering diagrams distinguish baseline application controls (blue) from **proposed, unimplemented** safety functions (yellow dashed boundaries). These diagrams are conceptual, not as-built drawings. The robot concept image generated for design exploration is not published as an actual MABEL hardware depiction.

To embed in the root README, use Markdown image references to the relative SVG paths above, prefixed by `docs/assets/`.
